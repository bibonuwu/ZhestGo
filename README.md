# Qoldau — ым тілінен қазақ сөзіне

**Авторы:** Ерланқызы Айшабибі, Берікқызы Ғайнижамал

**Qoldau** («қолдау» — поддержка) — веб-приложение для людей, которые не могут говорить.
Человек показывает жесты одной или двумя руками в веб-камеру, приложение распознаёт их,
строит грамматически правильное казахское предложение и **произносит его вслух по-казахски**.

**Работает без интернета и без платных сервисов.** Распознавание жестов, казахская
грамматика и казахский голос выполняются прямо в браузере. После первого открытия сайт
можно установить как приложение, и он будет работать офлайн всегда.

- **Жесты из 50 видеоуроков распознаются камерой**: повторите жест из урока на странице
  «Перевод» — появится его слово. На сайте 50 слов, у каждого есть видеоурок
  ([список](docs/WORDS.md)): словарь, обучение, быстрые фразы и подсказки показывают только
  их. Для части слов есть ещё простые жесты Qoldau (включаются в настройках).
- **Офлайн-грамматика казахского языка**: падежи, притяжательные формы, спряжение,
  отрицание, порядок слов. `мен | су | ішу | керек` → «Маған су ішу керек.»,
  `ертең | мектеп | бару` → «Ертең мектепке барамын.», `мен | сіз | жақсы көремін` →
  «Мен сізді жақсы көремін.»
- **Офлайн-голос**: бесплатные казахские голоса Piper (женский и мужской), ~60 МБ
  загружаются один раз.
- **Умный помощник**: подсказки следующего слова, быстрые фразы в одно касание,
  «часто используемые» фразы и самообучение на жестах пользователя.
- **Обучение своим жестам**: 2–3 дубля слова на странице «Обучение» — и камера узнаёт
  жест в вашем исполнении. Дубли (точки руки, кадр и видео 2,5 с) хранятся в браузере,
  видео можно сохранить в галерею или «Загрузки».
- **50 видеоуроков** — жесты, снятые командой Qoldau: замедленный просмотр, отметка
  «Выучил», тест «Проверь себя». Каждое видео ~50–110 КБ.
- **Рейтинг** (Firebase): регистрация, сколько жестов выучил каждый участник, тройка
  лидеров с именами на главной странице.
- **«Біздің жобамызды қолдаңыздар»** — поддержка через Kaspi и связь в Telegram;
  согласие на cookie и полный текст «Условий использования и Политики конфиденциальности».
- **«Сообщить о проблеме»** на видеоуроке и на произнесённой фразе и **«Обратная связь»**
  внизу сайта: сообщения приходят команде в Firestore (см. ниже).
- Видео с камеры никуда не отправляется. Интерфейс на казахском, русском и английском,
  светлая тема по умолчанию и тёмная, есть версия для телефона.

## Быстрый старт

Нужен Node.js 20+ и браузер Chrome, Edge или Safari.

```bash
npm install          # скачает модели распознавания и казахские голоса в public/
npm run dev          # http://localhost:5173
```

Продакшен-сборка:

```bash
npm run build        # готовый сайт в dist/ — это обычные статические файлы
npm start            # (необязательно) раздать dist/ вместе с API на http://localhost:8787
```

## Бесплатный хостинг навсегда

Основной сайт — Firebase Hosting (см. выше, `npm run deploy`). Серверная часть
**не нужна**: папка `dist/` — это статический сайт. Камера работает
только по **HTTPS** (или на `localhost`), а все бесплатные хостинги ниже дают HTTPS.

- **GitHub Pages** (рекомендую). Workflow уже есть:
  [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml).
  1. Загрузите проект в репозиторий GitHub (ветка `main`).
  2. Откройте Settings → Pages → Source: **GitHub Actions**.
  3. После каждого push сайт сам соберётся и опубликуется по адресу
     `https://<имя>.github.io/<репозиторий>/`.
- **Netlify** / **Vercel**: команда сборки `npm run build`, папка `dist`.
- **Cloudflare Pages**: ограничение 25 МБ на файл, поэтому файлы голоса (28 МБ)
  не выложатся. Приложение само скачает их с Hugging Face — только один раз, при
  загрузке голоса.

Если сайт открыт не с корня домена, задайте путь при сборке: `BASE_PATH=/repo/ npm run build`.

## Сайт, аккаунты и рейтинг — Firebase

Сайт опубликован на **https://qoldau-ai-kz.web.app** (Firebase Hosting, проект `qoldau-4630c`).
Каждая публикация копируется и на прежний адрес https://qoldau-ym.web.app, чтобы старые
ссылки и установленные приложения продолжали работать. Имя `qoldau-ai` занято другим
проектом Firebase, а точку в имени сайта `*.web.app` Firebase не допускает; адрес ровно
`qoldau.ai` — это купленный домен, подключаемый в консоли: Hosting → Add custom domain.

- **Аккаунты** — Firebase Authentication (почта + пароль). Пароль хранит Firebase, мы
  его не видим.
- **Рейтинг** — Cloud Firestore (регион `europe-west3`). Один публичный профиль на
  аккаунт: `users/{uid}` = имя, выученные жесты, их число и время изменения. Почта в
  Firestore не хранится.
- **Правила доступа** — [firestore.rules](firestore.rules): читать рейтинг могут все,
  менять профиль — только его владелец; принимаются только жесты из
  [src/data/signs.ts](src/data/signs.ts) (тест следит, чтобы списки совпадали).
- **Жалобы и отзывы** — коллекция `feedback/{id}`: тип (`report` — о уроке или фразе,
  `feedback` — о сайте), причина, о чём (`lesson:<id>` / `phrase:<текст>`), текст,
  контакт (если оставили), страница, язык, `uid` (если вошли) и время. Отправить может
  любой посетитель, читать с сайта — никто: команда читает их в **консоли Firebase →
  Firestore Database → feedback**. Пока новые правила не опубликованы (`npm run deploy`
  или `deploy.bat`), отправка отвечает «Не удалось отправить».
- **Публикация** одной командой (нужен `firebase login`):

  ```bash
  npm run deploy       # сборка в режиме firebase + Hosting + правила и индексы Firestore + копия на qoldau-ym
  ```

  На Windows то же самое делает **`deploy.bat`** — двойной клик: проверит вход в
  Firebase, сожмёт новые видео (если есть ffmpeg), прогонит тесты, соберёт и опубликует.

  В режиме `firebase` модели распознавания (~18 МБ) берутся с CDN Google, а голос — с
  Hugging Face, и кэшируются в браузере при первом использовании. Так каждый
  посетитель главной скачивает ~1–2 МБ, а не 21 МБ, и бесплатного лимита Hosting
  (10 ГБ трафика в месяц) хватает надолго.
- Один раз в консоли Firebase: **Authentication → Sign-in method → Email/Password →
  Enable**.
- Cookie: «Разрешить» — вход сохраняется после закрытия браузера, «Только
  необходимые» — до закрытия. Подробности на странице `#/privacy`.

## Видеоуроки

Исходные записи лежат в `video/` (C0921.MP4 … C0970.MP4, ~8 МБ каждая), список слов и
соответствие файлам — в [src/data/signs.ts](src/data/signs.ts). Команда

```bash
npm run videos       # нужен ffmpeg в PATH
```

сжимает их в `public/signs/<id>.mp4` (450×640, 25 к/с, без звука) и делает постер
`<id>.webp`: 405 МБ → 3,2 МБ. Уже сжатые файлы пропускаются.

Новое видео: файл в `video/`, строка в `SIGNS` (тема `emergency` — раздел «Шұғыл көмек»),
слово в [src/data/vocabulary.ts](src/data/vocabulary.ts) с той же категорией и id жеста в
`signIds()` в [firestore.rules](firestore.rules); затем `deploy.bat`. В окне урока слово
показывается и по слогам (Сә•лем) с отдельной кнопкой, которая произносит его по слогам.

### Распознавание жестов из видео

Камера узнаёт жесты по самим видеоурокам. Модель строится в два шага:

```bash
npm run landmarks    # MediaPipe по каждому кадру видео → video/landmarks/<id>.json (нужны ffmpeg и Chrome/Edge)
npm run sign-model   # точки → шаблоны жестов → src/data/signModel.json + проверка на всех 50 видео
```

- В каждом видео автоматически вырезается сам жест — без подъёма руки в начале и опускания
  в конце. Жест, который просто держат на месте, сокращается до 1 с. Если обрезка неверна,
  её можно задать вручную полем `trim` в `signs.ts` (так сделано для «үлкен»).
- Признаки кадра не зависят от человека и камеры: изгибы пальцев (по 3D-точкам),
  поворот ладони, положение рук относительно лица в ширинах лица, скорость. Точки
  веб-камеры дрожат сильнее, чем в видеоуроках, поэтому признаки усредняются за 0,1 с
  (и в шаблонах, и на камере).
- На камере каждый шаблон ищется в потоке методом DTW: жест можно показать в 2 раза
  быстрее или в 3 раза медленнее, чем в видео, правой или левой рукой (в том числе
  «зеркально», как повторяют видео новички). Если короткий жест оказался началом
  длинного (тыңдау → әйел), длинный его заменяет.
- Дубли со страницы «Обучение» становятся личными шаблонами того же DTW: камера узнаёт
  жест и так, как его показывает этот человек, а при равенстве личный вариант важнее
  урока.
- Пороги — в начале [src/gesture/signSpotter.ts](src/gesture/signSpotter.ts), веса
  признаков — в [src/gesture/signFeatures.ts](src/gesture/signFeatures.ts).

**Новое видео:** положить его в `video/`, добавить строку в `signs.ts` (с `wordId`), слово —
в `src/data/vocabulary.ts` и его грамматику — в `src/data/grammar.ts`, затем
`npm run videos`, `npm run landmarks`, `npm run sign-model`. Отчёт последней команды
покажет, узнаётся ли новый жест и не путается ли он с другими. `deploy.bat` делает эти шаги сам.

## Как пользоваться

1. **Аударма / Перевод** — нажмите «Включить камеру» и показывайте жесты из видеоуроков.
   Камера должна видеть лицо и руки (лучше — от головы до пояса). Внизу видео
   появляется распознанное слово с кольцом прогресса. Когда кольцо заполнится, слово
   добавится в предложение. Чтобы повторить то же слово, опустите руку и покажите снова. **Опустите руки на 2,5 с** — фраза соберётся по правилам
   грамматики и прозвучит.
   - «Следующее слово» — подсказки, какое слово обычно идёт дальше. Модель учится на
     ваших фразах.
   - «Быстрые фразы» — «Сәлем, досым!», «Маған су керек.», «Ертең мектепте оқимын.»
     и другие одним касанием (только из слов с видеоуроком); часто используемые фразы
     появляются со звёздочкой.
   - «Сообщить» у произнесённой фразы — сообщить команде об ошибке во фразе или голосе.
   - Клавиши: `Enter` — озвучить, `Backspace` — удалить последнее слово, `Esc` — очистить.
2. **Сөздік / Словарь** — 50 слов с видео: видеоурок, перевод, прослушивание. Если искомого
   слова нет, поиск так и говорит: «В нашем словаре этого слова пока нет…». Словарь можно
   использовать как коммуникационную доску без камеры. В окне урока кнопка «Сообщить»
   отправляет жалобу на видео, перевод или распознавание.
3. **Үйрену / Обучение** — запишите жест слова 2–3 раза. Дубли сохраняются в этом
   браузере (точки руки, кадр и видео 2,5 с, до 60 дублей) и сразу помогают распознаванию.
   Нажмите на дубль — откроется его видео и кнопка «Сохранить на устройство» (на телефоне —
   в галерею через меню «Поделиться», на компьютере — в «Загрузки»). На сервер дубли не
   отправляются; их можно экспортировать и импортировать.
4. **Баптаулар / Настройки** — раздел **«Офлайн-режим»**: загрузка казахского голоса
   (после загрузки «Источник голоса» сам переключается на него), установка приложения,
   место на диске. Также ведущая рука, режим распознавания (жесты
   из видеоуроков, простые шаблоны Qoldau, ваши жесты), время удержания жеста, пауза
   автоозвучки, скорость речи.

### Самообучение

Когда фраза произнесена, а слово не удалили, значит, жест распознан верно. Его кадры
добавляются в личные образцы, и распознавание постепенно подстраивается под руку
пользователя. Отключается в настройках («Учиться на моих жестах»). Образцы видны и
удаляются на странице «Обучение».

## Как это устроено

```
камера → MediaPipe (21 точка × 2 руки + лицо) ─┬→ 50 жестов из видео (DTW по шаблонам) ──┐
                                               ├→ KNN по личным образцам ─────────────────┼→ слово
                                               └→ шаблоны Qoldau (по желанию) ────────────┘
       → казахская грамматика (src/lang/kk) → голос Piper в Web Worker → звук
```

Всё тяжёлое кэшируется в браузере:

| Что | Размер | Когда сохраняется |
|---|---|---|
| Приложение, шрифты, модели распознавания | ~21 МБ | при первом открытии (service worker) |
| Казахский голос (движок + модель) | ~60 МБ | по кнопке в «Офлайн-режиме» |

- `src/gesture/` — распознавание: формы кисти (по 3D-координатам, не зависят от поворота
  руки), зоны относительно лица, трекер движения, KNN, стабилизация.
- `src/lang/kk/` — офлайн-грамматика: сингармонизм, классы звуков, падежи,
  притяжательность, личные окончания, спряжение (настоящее-будущее, прошедшее,
  отрицание, повелительное), построение предложения.
- `src/lang/predict.ts` — предсказание следующего слова (биграммы, учится на истории).
- `src/speech/` — офлайн-синтез речи: фонемизатор espeak-ng (WASM) и VITS-модель
  (ONNX Runtime) в Web Worker.
- `server/` — **необязательный** API: грамматика через Claude (`ANTHROPIC_API_KEY`) и
  голос Azure (`AZURE_SPEECH_KEY`). Без ключей и без сервера всё работает.

## Ограничения

- Жесты из видео сняты одним человеком. Проверка на имитации других людей (сдвиг и
  поворот рук, другой изгиб пальцев, скорость, наклон камеры, дрожание точек, 15–30 к/с):
  ≈ 97 % на умеренном разбросе и ≈ 92 % на сильном (повтор «зеркально» — ≈ 89 %). На
  реальных людях пороги стоит проверить. Если какой-то жест узнаётся плохо, запишите его
  2–3 раза на странице «Обучение» — дубли становятся личными шаблонами.
- Проверка всего приложения в браузере (видео вместо веб-камеры): 49 из 50 жестов
  узнаются стабильно. «Нан» — неустойчиво: ладонь-«нож» стоит ребром над другой ладонью,
  и MediaPipe по-разному оценивает её 3D-форму. Помогут пересъёмка (ладонь чуть
  развёрнута к камере) или свои записи на странице «Обучение».
- Простые шаблоны Qoldau — **упрощённая система** для веб-камеры, а **не официальный
  казахский жестовый язык**; по умолчанию они выключены, чтобы не мешать жестам из видео.
- Пороги распознавания подобраны на анатомической модели кисти. На реальной камере их
  стоит проверить: «Показывать детали распознавания» покажет, что видит система.
  Пороги лежат в `SHAPE_THRESHOLDS` (`src/gesture/handshape.ts`) и `MOTION_THRESHOLDS`
  (`src/gesture/motion.ts`).
