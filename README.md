# Qoldau — ым тілінен қазақ сөзіне

**Авторы:** Ерланқызы Айшабибі, Берікқызы Ғайнижамал

**Qoldau** («қолдау» — поддержка) — веб-приложение для людей, которые не могут говорить.
Человек показывает жесты одной или двумя руками в веб-камеру, приложение распознаёт их,
строит грамматически правильное казахское предложение и **произносит его вслух по-казахски**.

**Работает без интернета и без платных сервисов.** Распознавание жестов, казахская
грамматика и казахский голос выполняются прямо в браузере. После первого открытия сайт
можно установить как приложение, и он будет работать офлайн всегда.

- **100 разговорных слов** с готовыми жестами — работают сразу ([список](docs/WORDS.md)).
- **Офлайн-грамматика казахского языка**: падежи, притяжательные формы, спряжение,
  отрицание, порядок слов. `мен | су | ішу | керек` → «Маған су ішу керек.»,
  `ертең | мектеп | бару` → «Ертең мектепке барамын.», `мен | сіз | жақсы көремін` →
  «Мен сізді жақсы көремін.»
- **Офлайн-голос**: бесплатные казахские голоса Piper (женский и мужской), ~60 МБ
  загружаются один раз.
- **Умный помощник**: подсказки следующего слова, быстрые фразы в одно касание,
  «часто используемые» фразы и самообучение на жестах пользователя.
- **Обучение своим жестам** (например, настоящему казахскому жестовому языку).
- **50 видеоуроков** — жесты, снятые командой Qoldau: замедленный просмотр, отметка
  «Выучил», тест «Проверь себя». Каждое видео ~50–110 КБ.
- **Рейтинг** (Firebase): регистрация, сколько жестов выучил каждый участник, тройка
  лидеров с именами на главной странице.
- **«Біздің жобамызды қолдаңыздар»** — поддержка через Kaspi и связь в Telegram;
  согласие на cookie.
- Видео с камеры никуда не отправляется. Интерфейс на казахском, русском и английском,
  светлая тема по умолчанию и тёмная, есть версия для телефона.

## Быстрый старт

Нужен Node.js 20+ и браузер Chrome, Edge или Safari.

```bash
npm install          # скачает модели распознавания и казахские голоса в public/
npm run dev          # http://localhost:5173
```

Продакшен-сборка:

```bash
npm run build        # готовый сайт в dist/ — это обычные статические файлы
npm start            # (необязательно) раздать dist/ вместе с API на http://localhost:8787
```

## Бесплатный хостинг навсегда

Основной сайт — Firebase Hosting (см. выше, `npm run deploy`). Серверная часть
**не нужна**: папка `dist/` — это статический сайт. Камера работает
только по **HTTPS** (или на `localhost`), а все бесплатные хостинги ниже дают HTTPS.

- **GitHub Pages** (рекомендую). Workflow уже есть:
  [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml).
  1. Загрузите проект в репозиторий GitHub (ветка `main`).
  2. Откройте Settings → Pages → Source: **GitHub Actions**.
  3. После каждого push сайт сам соберётся и опубликуется по адресу
     `https://<имя>.github.io/<репозиторий>/`.
- **Netlify** / **Vercel**: команда сборки `npm run build`, папка `dist`.
- **Cloudflare Pages**: ограничение 25 МБ на файл, поэтому файлы голоса (28 МБ)
  не выложатся. Приложение само скачает их с Hugging Face — только один раз, при
  загрузке голоса.

Если сайт открыт не с корня домена, задайте путь при сборке: `BASE_PATH=/repo/ npm run build`.

## Сайт, аккаунты и рейтинг — Firebase

Сайт опубликован на **https://koldau.web.app** (Firebase Hosting, проект `qoldau-4630c`).

- **Аккаунты** — Firebase Authentication (почта + пароль). Пароль хранит Firebase, мы
  его не видим.
- **Рейтинг** — Cloud Firestore (регион `europe-west3`). Один публичный профиль на
  аккаунт: `users/{uid}` = имя, выученные жесты, их число и время изменения. Почта в
  Firestore не хранится.
- **Правила доступа** — [firestore.rules](firestore.rules): читать рейтинг могут все,
  менять профиль — только его владелец; принимаются только жесты из
  [src/data/signs.ts](src/data/signs.ts) (тест следит, чтобы списки совпадали).
- **Публикация** одной командой (нужен `firebase login`):

  ```bash
  npm run deploy       # сборка в режиме firebase + Hosting + правила и индексы Firestore
  ```

  В режиме `firebase` модели распознавания (~18 МБ) берутся с CDN Google, а голос — с
  Hugging Face, и кэшируются в браузере при первом использовании. Так каждый
  посетитель главной скачивает ~1–2 МБ, а не 21 МБ, и бесплатного лимита Hosting
  (10 ГБ трафика в месяц) хватает надолго.
- Один раз в консоли Firebase: **Authentication → Sign-in method → Email/Password →
  Enable**.
- Cookie: «Разрешить» — вход сохраняется после закрытия браузера, «Только
  необходимые» — до закрытия. Подробности на странице `#/privacy`.

## Видеоуроки

Исходные записи лежат в `video/` (C0921.MP4 … C0970.MP4, ~8 МБ каждая), список слов и
соответствие файлам — в [src/data/signs.ts](src/data/signs.ts). Команда

```bash
npm run videos       # нужен ffmpeg в PATH
```

сжимает их в `public/signs/<id>.mp4` (450×640, 25 к/с, без звука) и делает постер
`<id>.webp`: 405 МБ → 3,2 МБ. Уже сжатые файлы пропускаются, поэтому новое видео
достаточно положить в `video/`, добавить строку в `signs.ts` и снова запустить команду.

## Как пользоваться

1. **Аударма / Перевод** — нажмите «Включить камеру» и показывайте жесты. Внизу видео
   появляется распознанное слово с кольцом прогресса. Когда кольцо заполнится, слово
   добавится в предложение. **Опустите руки на 2,5 с** — фраза соберётся по правилам
   грамматики и прозвучит.
   - «Следующее слово» — подсказки, какое слово обычно идёт дальше. Модель учится на
     ваших фразах.
   - «Быстрые фразы» — «Көмектесіңіз!», «Кешіріңіз, дәретхана қайда?», «Мен түсінбеймін.»
     и другие одним касанием; часто используемые фразы появляются со звёздочкой.
   - Клавиши: `Enter` — озвучить, `Backspace` — удалить последнее слово, `Esc` — очистить.
2. **Сөздік / Словарь** — слова, для которых есть видео: видеоурок, рисунок кисти, зона тела, движение, описание,
   прослушивание. Словарь можно использовать как коммуникационную доску без камеры.
3. **Үйрету / Обучение** — запишите свой вариант жеста (2–3 раза) или добавьте своё слово.
   Данные хранятся в браузере, их можно экспортировать и импортировать.
4. **Баптаулар / Настройки** — раздел **«Офлайн-режим»**: загрузка казахского голоса,
   установка приложения, место на диске. Также ведущая рука, время удержания жеста,
   пауза автоозвучки, скорость речи.

### Самообучение

Когда фраза произнесена, а слово не удалили, значит, жест распознан верно. Его кадры
добавляются в личные образцы, и распознавание постепенно подстраивается под руку
пользователя. Отключается в настройках («Учиться на моих жестах»). Образцы видны и
удаляются на странице «Обучение».

## Как это устроено

```
камера → MediaPipe (21 точка × 2 руки + лицо) → форма кисти · направление · зона · движение
       → 100 шаблонов + KNN по личным образцам → стабилизация → слово
       → казахская грамматика (src/lang/kk) → голос Piper в Web Worker → звук
```

Всё тяжёлое кэшируется в браузере:

| Что | Размер | Когда сохраняется |
|---|---|---|
| Приложение, шрифты, модели распознавания | ~21 МБ | при первом открытии (service worker) |
| Казахский голос (движок + модель) | ~60 МБ | по кнопке в «Офлайн-режиме» |

- `src/gesture/` — распознавание: формы кисти (по 3D-координатам, не зависят от поворота
  руки), зоны относительно лица, трекер движения, KNN, стабилизация.
- `src/lang/kk/` — офлайн-грамматика: сингармонизм, классы звуков, падежи,
  притяжательность, личные окончания, спряжение (настоящее-будущее, прошедшее,
  отрицание, повелительное), построение предложения.
- `src/lang/predict.ts` — предсказание следующего слова (биграммы, учится на истории).
- `src/speech/` — офлайн-синтез речи: фонемизатор espeak-ng (WASM) и VITS-модель
  (ONNX Runtime) в Web Worker.
- `server/` — **необязательный** API: грамматика через Claude (`ANTHROPIC_API_KEY`) и
  голос Azure (`AZURE_SPEECH_KEY`). Без ключей и без сервера всё работает.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | режим разработки (Vite + необязательный API) |
| `npm run build` | проверка типов и сборка статического сайта в `dist/` |
| `npm run deploy` | сборка для Firebase и публикация на koldau.web.app |
| `npm start` | раздать `dist/` вместе с API на порту 8787 |
| `npm test` | тесты: формы кисти, движение, словарь, грамматика, подсказки |
| `npm run docs:words` | пересоздать `docs/WORDS.md` из словаря |
| `npm run videos` | сжать видео жестов из `video/` в `public/signs/` |

## Ограничения

- Жесты — **упрощённая система Qoldau** для веб-камеры, а **не официальный казахский
  жестовый язык**. Настоящие жесты можно добавить через «Обучение».
- Пороги распознавания подобраны на анатомической модели кисти. На реальной камере их
  стоит проверить: «Показывать детали распознавания» покажет, что видит система.
  Пороги лежат в `SHAPE_THRESHOLDS` (`src/gesture/handshape.ts`) и `MOTION_THRESHOLDS`
  (`src/gesture/motion.ts`).
- Грамматика покрывает типичные разговорные конструкции со 100 словами словаря. Для
  необычных сочетаний слов фраза может получиться упрощённой.
- Голос x_low (16 кГц) звучит понятно, но проще, чем облачные голоса.
